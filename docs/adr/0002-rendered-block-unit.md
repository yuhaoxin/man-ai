# 0002 翻译单元：按空行切分的渲染文本块

- 状态：接受
- 日期：2026-11-12
- 决策来源：[#4](https://github.com/yuhaoxin/man-ai/issues/4)、[#5](https://github.com/yuhaoxin/man-ai/issues/5)、[#6](https://github.com/yuhaoxin/man-ai/issues/6)

## 背景

分页器拿到的是已经渲染好的文本：可能含 SGR、退格叠加（`X\bX`）、悬挂缩进、表格列留白、页眉页脚、行尾断词，以及超过终端宽度的 literal 行。macOS 与 Linux 的渲染器对这些细节的处理并不一致。

翻译单元的选择决定三件事：请求数量与首屏延迟、失败回退的粒度、缓存复用的粒度。候选方案：

1. 解析 roff 语法树后按宏节点翻译：语义最准，但要把渲染器重新实现一遍。
2. 按行翻译：实现最简单，但一句跨行的话会被拆散，术语与语法上下文丢失。
3. 按启发式结构（缩进、列表、表格）切分：能保留更多结构，但两平台输出差异会让启发式频繁失效。
4. 整页一次请求：上下文最全，但首屏必须等整页，且单点失败会拖垮整页。
5. 按空行切块：块边界来自渲染器的段落分隔，不依赖内容形状。

## 决策

采用方案 5。

- 空行是唯一块边界；连续非空行组成一个块，块不可再分，不设长度上限。
- 块保存原始字节与 UTF-8 解码结果。原始字节原样送模型，回退时原样写出；解码失败的块不送模型。
- 结构层不解析 SGR、退格叠加、页眉页脚、表格或缩进，也不重排、不折行、不重算列宽。
- 每块一次独立请求，块间无共享状态；结果按块序写出。
- 样式序列要求逐字节保留，由提示词约束；结构层只做结构校验（孤悬退格、非法 SGR、字面 `ESC[`），不检查长度比例、行数或语义。
- 失败回退的粒度是块：重试一次仍失败就写出该块原文，其余块继续。

## 后果

- 实现与缓存都只需要处理「一段字节进、一段字节出」，不依赖 roff 或渲染器版本。
- 块可以在不同页面之间复用缓存：只要字节相同，键就相同。
- 块内出现页眉页脚时无法单独处理，只能靠提示词要求保持原样；表格列对齐与折行也由模型负责，结构层不校验。
- 单块超出模型上下文时整块回退；长能力表（如 terminfo）可能整表保持英文。
- 跨块术语一致性没有承载点；要支持需要给请求带上文，属于后续迭代。
- 首屏延迟由最慢的靠前块决定；并发只压缩总时长，不改善单块延迟。
