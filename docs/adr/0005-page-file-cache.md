# 0005 缓存：整页文件布局

- 状态：接受
- 日期：2026-11-18
- 决策来源：[#36](https://github.com/yuhaoxin/man-ai/issues/36)、[#44](https://github.com/yuhaoxin/man-ai/issues/44)

## 背景

阅读器改造后整页成为读取与显示的单位，块级内容寻址的收益（同段文本跨页共享）
不再值得付出两级目录与逐块键比对的复杂度；`man -k` 整批条目随 `-k` 路径删除，
块级寻址失去最后一个跨页复用场景。

## 决策

- 条目 = `$XDG_CACHE_HOME/man-ai/<语言规范标签>/<页名>.<section>.md`，页名小写，
  从预转换后文本第一行页眉 `NAME(SECTION)` 解析；解析失败的页不缓存。
- 文件内容 = 整页译文 Markdown，首行是 HTML 注释形式的键字段：
  `v`、`prompt`、规范化端点、模型名、思考强度、预转换全文 BLAKE3-128。
  命中 = 文件名相同且字段逐一一致，输出前剥除注释行。
- 整页粒度：命中直出零请求；未命中按块译完、全部采用才落盘；含回退块的页不写。
- `--retranslate` 跳过读取、强制重译，采用后照常覆盖写。
- 旧 `v1/` 哈希目录在进入翻译路径时删除；容量剪枝（mtime 删到 80%）与
  tmp+rename 原子写沿用 0003 的机制。

## 后果

- 块级跨页共享与 `-k` 整批缓存不再存在；同一页面换端点、模型、思考强度、
  提示词版本自然不命中。
- 并发同页 miss 各自请求、后写覆盖，机制不变。
- 0003 的键字段语义（不含路径、mtime、版本号、并发度、`max_tokens`）全部保留，
  只是载体从哈希文件名改为注释字段。
